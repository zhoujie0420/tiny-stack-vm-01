Tiny stack VM: a 32-bit wrapping ISA interpreter. One run answers a whole set: for every id it reads /input/<id>/program.bin and /input/<id>/input.bin and writes /output/<id>/stdout.bin and /output/<id>/exit.txt.

## Run it

```sh
node main.ts
```
